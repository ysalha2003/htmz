# 05 — خطة نظام التصميم: صارم لكن طبيعي

> الهدف: نظام تصميم كامل لتطبيقات الأعمال، مبني بـ CSS وHTML أصليين فقط، بلا إطار مكوّنات JavaScript، يصلح للعربية RTL والإنجليزية LTR، ويمكن فرض الالتزام به دون خط بناء كبير.

## 1. تقييم الوضع الحالي

`starter/public/design.css` (138 سطرًا، 48 رمزًا، 12 صنف مكوّن) نقطة بداية صحيحة الاتجاه وغير كافية:

| ما هو صحيح ويبقى | ما يجب أن يتغير |
|---|---|
| الرموز كمتغيرات CSS بسابقة `--ds-` | توسيع الرموز لتشمل الحركة والطبقات (z) والحدود الدلالية وأحجام اللمس |
| طبقات `@layer tokens, reset, elements, components, responsive` | إعادة ترتيب: `reset, tokens, base, layout, components, utilities, overrides` وحذف طبقة `responsive` (الاستجابة تصبح داخل كل مكوّن) |
| الخصائص المنطقية | فرضها بالفاحص ومنع الخصائص الفيزيائية |
| `:focus-visible` بحلقة واضحة | يبقى؛ يضاف `scroll-margin` للعناصر المركَّزة |
| الفاحص بلا تبعيات | يوسَّع (القسم 6) |
| ألوان Hex ثابتة | الانتقال إلى `oklch()` مع اشتقاق بـ `color-mix()` وتفعيل `light-dark()` اختياريًا |
| `@media (max-width: 760px)` (Desktop-First) | **قلب الاتجاه** إلى Mobile-First بـ `min-width` واستعلامات الحاوية |
| خط `"Segoe UI", Tahoma, Arial` | مكدس خطوط يراعي العربية على كل الأنظمة (القسم 4) |
| لا وضع داكن، لا تقليل حركة | إضافة `prefers-reduced-motion` إلزاميًا، والوضع الداكن اختياريًا |
| 12 مكوّنًا | ~22 مكوّنًا أساسيًا لتطبيق أعمال (القسم 3) |

## 2. الرموز (Tokens)

### 2.1 الفئات

| الفئة | أمثلة | ملاحظات |
|---|---|---|
| الألوان الدلالية | `--ds-color-bg`, `-surface`, `-surface-raised`, `-text`, `-text-muted`, `-border`, `-primary`, `-primary-contrast`, `-success`, `-warning`, `-danger`, `-info`, `-focus` | **دلالية لا وصفية**: لا `--ds-blue-500`. كل لون له نظير داكن عبر `light-dark()` عندما يُفعَّل الوضع الداكن |
| المسافات | `--ds-space-1 … -10` على شبكة 4px بوحدة `rem` | تبقى كما هي |
| الأحجام | `--ds-size-touch: 44px`, `--ds-size-control: 2.75rem`, `--ds-size-icon`, `--ds-width-content: 72rem`, `--ds-width-sidebar` | حد اللمس 44px (أعلى من WCAG 2.2 AA وهو 24px) |
| الطباعة | `--ds-font-sans`, `--ds-font-mono`, `--ds-text-xs … -2xl` بـ `clamp()`، `--ds-leading-tight/normal/loose`, `--ds-weight-*` | ارتفاع السطر للعربية ≥ 1.6 في المتن |
| الحدود والزوايا | `--ds-radius-sm/md/lg/full`, `--ds-border-width`, `--ds-border-color` | |
| الظلال والارتفاع | `--ds-shadow-1/2/3` | |
| الحركة | `--ds-duration-fast/base/slow`, `--ds-ease` | تصبح `0ms` تحت `prefers-reduced-motion` |
| الطبقات | `--ds-z-sticky`, `-drawer`, `-toast` | `dialog` و`popover` يستخدمان الطبقة العليا الأصلية فلا تحتاجان z |
| الحاويات | `--ds-container-sm: 30rem`, `-md: 48rem`, `-lg: 64rem` | تُستخدم في `@container` |

### 2.2 قواعد

1. المكوّنات تشير إلى الرموز فقط؛ أي لون أو مسافة أو حجم خام خارج طبقة الرموز خطأ يرفضه الفاحص.
2. الرموز الدلالية فقط هي الواجهة العامة. الرموز الخام (إن وُجدت لوحة ألوان) تُعرَّف في طبقة داخلية ولا تُستخدم مباشرة.
3. تغيير الهوية البصرية لتطبيق = ملف `theme.css` يعيد تعريف الرموز الدلالية فقط، في طبقة `overrides`.

## 3. المكوّنات الأساسية (v1)

| المكوّن | التقنية الأصلية | JavaScript؟ |
|---|---|---|
| الهيكل (شريط علوي، تنقل جانبي/سفلي، محتوى) | Grid + Container Queries + `env(safe-area-inset-*)` | لا |
| التنقل في الجوال (درج) | `<details>` أو `popover` + `inert` للخلفية | لا |
| الأزرار (أساسي، ثانوي، هادئ، خطر، أيقونة) بأحجام | `button` + أصناف | لا |
| الحقول (نص، رقم، تاريخ، بحث، نص طويل، اختيار، مربع، زر راديو، مفتاح) | ضوابط أصلية + `:user-invalid` + `accent-color` | لا |
| مجموعة حقل (تسمية، تلميح، خطأ) | `label` + `aria-describedby` + `:has(:user-invalid)` | لا |
| شريط بحث وفلاتر (رقائق) | `<search>` + `form method=get` + `details` للفلاتر المتقدمة | لا |
| الجدول | `table` دلالي + تمرير أفقي محتوى + نمط «بطاقات» تحت حاوية ضيقة عبر `@container` | لا |
| القائمة (عنصر/تفاصيل) | `ul` + `a` + `aria-current` | لا |
| البطاقة | `article`/`section` | لا |
| الشارة والحالة | `span` بأصناف دلالية | لا |
| التنبيه | `div role=alert/status` | لا |
| الإشعار العابر (Toast) | منطقة `role=status` + `popover=manual` | إظهار/إخفاء فقط (طبقة التحسين) |
| الحوار | `<dialog>` + `method=dialog` + `@starting-style` | `showModal()` إلى أن ينتشر `commandfor` |
| القائمة المنبثقة | `popover` + `popovertarget` | لا |
| التبويبات | روابط عادية + `aria-current` (كل تبويب عنوان حقيقي) | لا |
| ترقيم الصفحات | روابط | لا |
| مسار التنقل (Breadcrumb) | `nav` + `ol` | لا |
| الحالة الفارغة | قالب HTML | لا |
| حالة التحميل | `aria-busy` + هيكل (skeleton) بـ CSS | تضعها طبقة التحسين |
| رابط التخطي والمخفي بصريًا | أصناف أدوات | لا |
| الأكورديون | `details name` | لا |
| شريط الإجراءات السفلي الثابت في الجوال | `position: sticky` + `inset-block-end: env(...)` | لا |

**لا يوجد مكوّن واحد في v1 يحتاج JavaScript ليُعرض أو ليعمل أساسًا.** JavaScript يظهر فقط للحوارات المشروطة (إلى أن تنتشر أوامر الاستدعاء) ولحالات التحميل التي تضعها طبقة التحسين.

## 4. العربية وRTL وLTR

- **الاتجاه من `<html dir>`** وكل التخطيط بخصائص منطقية. الفاحص يرفض `left/right/margin-left/padding-right/text-align: left|right/float`.
- **عكس الأيقونات الاتجاهية** (أسهم، رجوع) عبر `:dir(rtl) .ds-icon-directional { transform: scaleX(-1) }`.
- **العزل ثنائي الاتجاه:** المصطلحات اللاتينية والأرقام والمعرّفات داخل نص عربي تُغلّف بـ `<bdi>` أو صنف `unicode-bidi: isolate` (الفاحص لا يفرض هذا لكنه موثق في الكتالوج).
- **الأرقام:** سياسة واضحة لكل تطبيق (أرقام عربية مشرقية أو غربية) تُطبَّق في الخادم عبر `Intl` أو ما يعادله، مع `font-variant-numeric: tabular-nums` في الجداول.
- **مكدس الخطوط:** `system-ui, -apple-system, "Segoe UI", Roboto, "Noto Sans Arabic", "Noto Naskh Arabic", Tahoma, sans-serif`. لا خطوط ويب في v1 (لا طلبات خارجية، لا FOUT). خط ويب محلي اختياري في `theme.css`.
- **الطباعة:** حجم المتن 1rem (16px) حدًا أدنى في الجوال (يمنع تكبير iOS التلقائي عند التركيز)، ارتفاع سطر 1.6–1.7 للعربية، `text-wrap: balance` للعناوين.
- **اختبار الاتجاهين إلزامي:** كل مكوّن يُعرض في الكتالوج بـ `dir=rtl` و`dir=ltr` جنبًا إلى جنب.

## 5. إعادة استخدام المكوّنات: تحليل الخيارات

| الخيار | التعقيد | التوافق مع «أي خادم» | الحكم |
|---|---|---|---|
| **أمثلة HTML جاهزة للنسخ (كتالوج)** | أدنى | كامل | **أساسي.** الكتالوج هو المصدر الأول: HTML + أصناف + ملاحظات وصول |
| **أجزاء قوالب الخادم (Partials)** | منخفض | كامل (كل إطار له قوالبه) | **الطريقة الموصى بها لإعادة الاستخدام في كل تطبيق.** العدة تقدم الأمثلة بصيغة Jinja/Blade/Go templates للخادمين المرجعيين فقط |
| Web Components أصلية | متوسط | كامل لكن يحتاج JS لكل مكوّن | **محدود:** فقط للسلوكيات التي تحتاج JS فعلًا (مثلًا `<ds-combobox>` مستقبلًا). ليست في v1 |
| تركيب HTML وقت البناء | متوسط | يفرض أداة بناء | **مرفوض** (يناقض «بلا بناء») |
| Declarative Shadow DOM | متوسط-عالٍ | كامل | **غير ضروري:** العزل الذي يقدمه تحققه الطبقات والبادئات، ويكسر توريث الرموز ويعقّد الأنماط العامة |

## 6. الصرامة: كيف نمنع كسر النظام دون خط بناء؟

### 6.1 بلا تبعيات (يعمل بـ Node أو Python فقط، أو كفحص CI)

يوسَّع `tools/design-check.mjs` الحالي ليفحص:

1. كل `var(--ds-*)` مُعرَّف.
2. لا ألوان خام (`#`, `rgb`, `hsl`, `oklch`) خارج طبقة الرموز.
3. لا أرقام بوحدات `px`/`rem` للمسافات والأحجام خارج طبقة الرموز (قائمة سماح صغيرة: `1px` للحدود، `0`).
4. **لا خصائص فيزيائية** (`margin-left`, `padding-right`, `left`, `right`, `text-align: left|right`, `float`).
5. لا `!important` خارج طبقة `utilities`.
6. لا `style=` ولا `<script>` مضمّن ولا `on*=` في القوالب.
7. لا `@import url(` ولا طلبات خارجية.
8. **مصفوفة التباين الكاملة** المولَّدة من الرموز الدلالية (كل نص على كل سطح): ≥ 4.5:1 للنص و≥ 3:1 للضوابط والحدود، للوضعين الفاتح والداكن.
9. وجود `@media (prefers-reduced-motion: reduce)` يُصفّر رموز المدة.
10. كل مكوّن في الكتالوج له مثال بالاتجاهين.

### 6.2 أدوات اختيارية للتطوير فقط

- **Playwright:** اختبارات تفاعل + لقطات بصرية للكتالوج في الاتجاهين وعرضين (390px و1280px) وثلاثة محركات.
- **axe-core** عبر Playwright: صفر انتهاكات من مستوى serious/critical في الكتالوج والتطبيق المرجعي.
- **Stylelint** مع إعداد صغير (اختياري): يكرر بعض قواعد الفاحص بتقارير أدق في المحرر.

### 6.3 الاتفاقيات

- بادئة واحدة `ds-` للأصناف، نمط `ds-component`, `ds-component-part`, `ds-component--variant`.
- الطبقات تحمي من حروب الخصوصية؛ التطبيق يكتب في `overrides` فقط.
- الكتالوج (`design-system.html`) هو مصدر الحقيقة: ما ليس فيه ليس جزءًا من النظام.

## 7. ما يُستبعد عمدًا من v1

- خطوط ويب، أيقونات SVG مضمّنة كمكتبة (تُقدَّم 20 أيقونة أساسية كـ sprite اختياري فقط).
- مكوّنات JS (منتقي تاريخ مخصص، صندوق تحرير وسرد غني، سحب وإفلات، مخططات).
- ثيمات متعددة جاهزة (ثيم واحد افتراضي + دليل تخصيص).
- وضع داكن إلزامي (يُقدَّم اختياريًا عبر `light-dark()` إذا اكتملت الرموز له).
