# نظام التصميم الموحّد — عقد صارم قابل للفحص

## المبدأ
جميع قيم ألوان الواجهة والخطوط والمسافات والحدود والظلال والأحجام تُعرّف في `public/design.css` ضمن `:root` باستخدام أسماء `--ds-*`. تستخدم مكونات `.ds-*` هذه المتغيرات بدل الألوان الثابتة في كل شاشة.

### التوكنز
- `--ds-color-*`: خلفية، أسطح، نص، حدود، Primary، Success، Error، Focus.
- `--ds-space-*`: شبكة مسافات محدودة 0، 1، 2، 3، 4، 5، 6، 8، 10.
- `--ds-text-*` و`--ds-font`: سُلّم خط ثابت وخط نظام بدون تحميل خارجي.
- `--ds-radius-*` و`--ds-border-width` و`--ds-shadow`: هندسة متسقة للمكونات.

### المكونات الحالية
`ds-shell`، `ds-topbar`، `ds-card`، `ds-button`، `ds-button-quiet`، `ds-pill`، `ds-input-row`، `ds-tabs`، `ds-alert`، `ds-project-list`، `ds-panel`، `ds-footer`.

استخدم عناصر HTML أصلية أولًا: `<button>`, `<form>`, `<a>`, `<label>`, `<input>`, `<nav>`. لا تُنشئ DSL خاصة بالمكونات؛ يمكن للخادم إنتاج نفس المكونات من أي template engine.

### قابلية الاستخدام
- `lang="ar" dir="rtl"` وإزاحات CSS منطقية `inline/block` تسمح باتجاهين، مع مراجعة كل استخدام جديد.
- `focus-visible` واضح، و`skip link`، وحقل بحث مع label.
- الرسائل الحية ضمن `role="status"`، والأخطاء `role="alert"`، وإدارة التركيز بعد استبدال اللوحات القابلة للتركيز.
- Responsive grid ينتقل إلى عمود واحد عند 760px؛ لا توجد JavaScript breakpoints.

## نظام ضبط جودة حقيقي
نفّذ `npm run check:design`؛ الفاحص يمنع الألوان الخام خارج منطقة التوكنز، ويرفض الإشارات إلى توكنز غير معرّفة، ويمنع CSS/JavaScript المضمّنَيْن في صفحة البداية. يقيس الفاحص أيضًا تباين ستة أزواج ألوان نص/خلفية ويمنع ما دون 4.5:1. يقيس الفاحص أيضًا تباين ستة أزواج ألوان نص/خلفية ويمنع ما دون 4.5:1. وهو Guard مبدئي لا يحل محل تدقيق UI وWCAG كامل.

## قواعد التطوير
1. لا تكتب `style="..."` في القوالب.
2. لا تضف Hex/RGB إلى قواعد المكونات؛ استخدم توكن معرفًا.
3. لا تضف مكتبة أيقونات أو خطوط خارجية دون ضرورة إنتاجية.
4. اختبر RTL وmobile والفوكس باستخدام متصفحات فعلية.
5. لا تعدّل توكنات Primary عند تصميم شاشة جديدة؛ غيّر theme على مستوى `:root` إن كان مطلوبًا.
6. قابلية الوصول والتباين والتحقق البصري لا تختزل في Design Token lint وحده.
